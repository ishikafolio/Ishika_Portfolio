Review: open CareConnect_Prototype.html in your browser. It is self-contained and works offline. Click buttons and navigation, or use the Parent/Caregiver shortcuts. Pairing, verification, consent, confirmation, invitations, editing and preferences appear as sheets, preserving the 10-screen scope.

Figma import (editable native text): import figma-importer/manifest.json as a local development plugin in Figma, then run it in the existing CareConnect design file. The importer creates the 10 frames with native text and editable shapes; named layers, colours and typography are preserved. The public Atkinson Hyperlegible Next font must be available in Figma.

Alternative: drag the ten files in screens/ onto the Figma canvas. SVG import preserves editable vector objects; Figma may outline SVG text. Use the importer when native text layers are required.

The HTML prototype is for interaction review, not a production app. Calls, messages, alerts, account verification, consent persistence and medication records are simulated; nothing is sent. The font is embedded for offline use. Medicine details, family names and timestamps are illustrative sample data.

Colours: Iris #5146A6; warm white #FAF8F5; navy #25304A; lavender #EFECFA; peach #F8E4D7; pending amber #805000 on #FFF0CE.
Font: Atkinson Hyperlegible Next. Parent-facing body text 20px, supporting labels 18px, primary controls 64px.

The file could not be updated directly through the Figma integration because its Starter-plan tool limit was reached. This package contains the complete screens for import into the approved CareConnect file.
